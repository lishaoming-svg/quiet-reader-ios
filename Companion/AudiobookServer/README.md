# 墨阅听书生成器

该程序在 Windows 本地把墨阅发送的章节正文转换为 M4A 音频。音频下载到 iPhone 后可以离线播放。

生成任务、章节正文和逐句时间轴会持久化到 `data`。服务重新启动后会继续尚未完成的队列，并可把同一本书的已完成章节导出成 `.qraudio` 逐句伴读包。

## 立即启动

CosyVoice 已安装后，双击 `打开墨阅听书.vbs` 即可。它会在后台启动服务并自动打开“墨阅桌面伴读台”，浏览器中可以查看当前章节、总进度、完整任务列表和失败原因，也可以下载已经完成的 `.qraudio` 伴读包。

桌面伴读台右上角提供“停止服务”。书籍卡片可以删除整本生成配置，章节任务页可以删除单章任务；删除操作会同步清理电脑上的任务文件、音频和旧伴读包。需要查看启动错误或详细模型日志时，再双击 `启动墨阅听书.cmd` 使用终端诊断入口。

也可以通过 PowerShell 手动选择引擎：

```powershell
cd Companion\AudiobookServer
python -m pip install -r requirements.txt
.\start.ps1 -Engine sapi
```

浏览器控制台的“连接手机”页面提供配对二维码，随后在 iPhone 墨阅听书面板中扫码。电脑切换 Wi-Fi、iPhone 热点或数据线网络后，页面会检测当前活动地址并更新二维码。Windows 第一次询问网络权限时允许专用网络访问。

生成概览在任务运行时每 5 秒检查一次，空闲时每 30 秒检查一次。数据没有变化时页面不会重新绘制，切换到其他浏览器标签后会暂停检查。

## CosyVoice 3

首次安装需要下载模型和 Python 依赖：

```powershell
.\install-cosyvoice.ps1
```

当前模型和运行环境合计约 15 GB，安装时还会使用下载缓存，建议预留至少 25 GB 空间。首次安装时间取决于网络速度，完成后可以全程离线合成。

准备一段具有使用权的清晰单人参考音频，以及与音频逐字一致的文字：

```powershell
.\start.ps1 -Engine cosyvoice `
  -PromptAudio 'D:\voices\reader.wav' `
  -PromptText '这里填写参考音频中准确说出的文字。'
```

参考音频建议为 5 至 15 秒、无背景音乐、无混响的 WAV 文件。生成器只监听本机局域网并使用随机配对令牌，切勿把端口直接暴露到公网。

启动后让电脑与 iPhone 连接同一局域网，在墨阅的阅读页点击耳机按钮，再扫描电脑页面上的配对二维码。听书面板默认选择多角色对话，点击“缓存未读章节并提交电脑”后由电脑生成当前章及后续章节；伴读包同步完成后，关闭电脑或离开局域网也能继续听。

CosyVoice 启动后提供三种朗读模式：自然女声、沉稳旁白和多角色对话。多角色模式会识别引号内台词及附近的说话人线索，为旁白、主角、男性和女性角色分别生成，并把逐段时间轴一同传给 iPhone，使阅读正文随播放位置自动移动。

## 整本预生成与传输

1. 在 iPhone 阅读页打开听书面板。
2. 点击“缓存未读章节并提交电脑”，App 会从当前阅读章节开始并行补齐后续正文，并通过一个批量请求上传。
3. 等待手机显示提交完成，随后可以离开听书页面，电脑会继续生成。
4. 再次连接电脑后点击“同步电脑已完成伴读包”。

生成过的整本包保存在 `data\packages`。也可以用 Windows Apple Devices 的文件共享把 `.qraudio` 直接添加到墨阅，再从 App 听书面板导入。包内包含章节 M4A、逐句时间轴、多角色标识和 SHA-256 校验值。
