# 全网书源内置目录

## 输入

- 用户提供目录：`D:\开源阅读书源全网合集(2)`。
- 原始文件：248 个，约 555 MB；包含 244 个 JSON、2 个 ZIP 和 2 个 TXT。
- 生成过程不会修改输入目录。

## 生成规则

- 读取 UTF-8、UTF-8 BOM 和 GB18030。
- 递归读取 ZIP 内 JSON/TXT，单条压缩包成员限制为 64 MB。
- 严格 JSON 失败后尝试连续 JSON、平衡对象恢复及全角 JSON 标点修复。
- 以 `bookSourceUrl + bookSourceName` 作为逻辑身份去重，优先保留更新时间较新、规则较完整的版本。
- 给每条书源分配稳定的 `archive.<sha256>` 标识并强制默认关闭。
- 仅保留墨阅模型可识别的顶层字段与四段规则，未知字段不进入运行时目录。

## 结果

- 原始书源记录：102,300。
- 去重内置书源：25,968。
- 当前兼容：6,223。
- 部分兼容：15,066。
- 暂不支持：4,679。
- 分片数量：64。
- 压缩资源总量：约 21 MB。

具体问题计数、恢复记录、分片大小和 SHA-256 位于 `App/Resources/SourceCatalog/source-catalog-manifest.json`。
