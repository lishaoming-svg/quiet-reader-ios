# 墨阅 QuietReader

墨阅是一款面向个人使用的原生 iOS 无广告阅读器。当前版本支持导入声明式 JSON 书源、跨书源搜索、精确阅读进度、多种翻页方式、阅读记录、书签和批量离线缓存。

## 当前能力

- iOS 17+，SwiftUI + SwiftData。
- 从 JSON 文本、文件或远程 URL 导入书源。
- 随 App 内置 25,968 条去重书源，支持按名称、分组、域名和兼容性筛选后导入。
- 从单个书源的排行榜与分类入口直接浏览书籍，支持常见文本和 JSON 榜单配置。
- 一键清理未启用且未被书架使用的冗余源，并用同一按钮快速跳到源列表顶部或底部。
- 导入前预览新增、更新和已有状态。
- 常用 Legado CSS 链式规则、CSS Selector、基础 JSONPath 与正则替换。
- 相对书源地址、当前节点属性、多页目录和单章多页正文连续读取；重复目录项按正文中的最终位置去重并重新编号。
- 搜索历史、详情、目录、正文、单章自动缓存和批量章节缓存。
- 书架列表/网格布局切换，书源按名称、分组或域名筛选并批量启停。
- 正文请求遇到超时或连接中断时自动重试，并用中文说明最终失败原因。
- 正文自动还原常见拼音敏感词混写，并清除汉字间的星号、全角遮挡符和零宽字符；普通英文保持原文。
- 搜索结果按书名或作者相关性排序、按作品聚合并可在详情页换源，同时过滤书源返回的推广伪结果。
- 章节内字符锚点、章节进度、全书进度和精确续读。
- 垂直滚动、水平滑动分页和无动画分页。
- 左右点击翻页、中央菜单、章节跳转和进度拖动。
- 最近阅读、今日/本周/本月/累计时长和阅读明细。
- 位置书签、书签摘要、书签列表和精确跳转。
- 中文阅读界面、宋体正文、两字段首缩进、三档页面留白、字号、行距和四种纸张主题。
- 滚动与分页模式共享正文排版；分页首屏独立展示章节标题，并保留轻量页眉、页码和全书进度。分页器会为 SwiftUI 实际行高保留安全空间，页尾文字完整显示且下一页连续衔接。
- 无广告、无分析 SDK、无强制账号；需要认证的第三方书源可使用独立网页登录。

## 生成 Xcode 工程

项目使用 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 描述工程：

```bash
brew install xcodegen
xcodegen generate
open QuietReader.xcodeproj
```

Windows 环境不能运行 Xcode。推送到 GitHub 后，可在 Actions 中运行 `构建 iOS 测试包`，下载 `QuietReader-unsigned-ipa` 构建产物，再使用 AltStore 或 Sideloadly 以自己的 Apple ID 签名安装。

第三方书源的实时链路可在 Actions 中手动运行 `在线书源冒烟测试`。该测试会在 iPhone 模拟器中使用 App 自身的书源引擎读取所有启用精选源，并单独核验饿狼小说和森林文学的《异悚》目录数量、前三章顺序、连续索引、“第一章 第一个人”合并后正文长度及章末标记；不纳入每次提交的固定测试，以免第三方服务临时故障阻断正常构建。

## 书源边界

当前书源格式兼容 Legado 的常用顶层字段，以及搜索、发现、详情、目录和正文规则结构。引擎覆盖常用声明式规则，支持普通网页登录 Cookie 同步；暂不支持 Legado JavaScript 桥接、脚本登录界面、验证码自动处理、复杂 POST、XPath 和付费操作。

“书源”页的“内置源库”来自用户提供的全网合集：102,300 条原始记录经格式修复和“地址 + 名称”去重后形成 25,968 条目录，其中 6,103 条标记为当前兼容、15,186 条部分兼容、4,679 条暂不支持。完整规则按 64 个压缩分片随 App 分发，默认不批量启用，避免一次搜索向数千站点同时发起请求。

当前阅读器暂未实现文本高亮与笔记、TTS、跨设备同步、本地 EPUB/TXT 和仿真卷页。

导入页的“载入精选源”保留从用户合集筛选并转换的 5 条无需登录规则。饿狼小说、森林文学和快眼看书默认启用；B5200 因连接不稳定且《异悚》目录缺章，五二书库因把全书网页分页误作章节目录，均已移入备用组并默认停用。完整性检查会核验指定目录数量、正文长度、章末内容及目录结构。

正文解析会保留 `<p>`、块级元素和 `<br>` 表达的自然段，清除脚本、站点提示、分页标题与“本章未完”提示。阅读器以宋体、两字首行缩进、舒适行距和段落间距显示正文；升级后会自动刷新三个默认精选源留下的旧单行缓存。

分页正文使用同一组页眉、页脚、留白和章节标题高度常量计算可用区域，并额外预留一整行渲染空间。回归测试会把所有页面文字重新拼接后与排版原文逐字比较，同时测量每页 SwiftUI 文本的实际高度。

饿狼小说和森林文学的目录规则只读取“正文”区域，跳过页面顶部倒序展示的“最新章节”。引擎对分页目录中的重复 URL 保留最终位置，续读进度和书签优先按章节 URL 恢复，目录纠正后仍能回到原章节。

Legado 源码结构、界面能力和后续实现顺序见 [`notes/legado-gap-audit.md`](notes/legado-gap-audit.md)。

重新编译用户提供的源库：

```powershell
$env:PYTHONIOENCODING='utf-8'
python scripts\compile-source-catalog.py 'D:\开源阅读书源全网合集(2)' 'App\Resources\SourceCatalog'
python scripts\verify-source-catalog.py 'App\Resources\SourceCatalog'
```

仅应连接用户有权访问的内容服务。
