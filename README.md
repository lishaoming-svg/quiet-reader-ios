# iBooks

iBooks 是一款面向个人使用的原生 iOS 无广告阅读器。当前版本支持导入声明式 JSON 书源、跨书源搜索、精确阅读进度、多种翻页方式、阅读记录、书签、批量离线缓存和由 Windows 本地生成的离线听书。

## 本地图书与新版书库

界面采用新版苹果图书的白色书库、封面网格、继续阅读和简洁阅读页布局，保留已有的网络书源和离线听书功能。主页右上角可进入阅读记录与书源管理。

在“书库”点右上角 **更多 → 导入图书**，可从系统“文件”一次选择多本书；也可以从其他 App 的分享菜单选择用 iBooks 打开。导入在本机后台完成，支持取消、逐文件错误提示和重复导入去重。相同文件重新导入会恢复本地正文并保留阅读位置，不要求原文件一直留在原处。

| 格式 | 处理方式 |
| --- | --- |
| EPUB | Readium 原书精排，保留 CSS、字体、插图、目录、锚点与固定版式 |
| TXT | UTF-8、带 BOM 的 UTF-16/32、GB18030、Big5 等常见编码；识别中英文章节标题，超长正文自动分段 |
| DOCX | 提取元数据、Word 标题目录、段落和表格文字，隐藏修订中已删除的文字 |
| DOC | Word 97 及之后的二进制文档，按 MS-CFB/FIB/CLX 的逻辑顺序还原正文；也兼容以 DOC 扩展名保存的 RTF |
| MOBI / AZW / AZW3 | libmobi 解析未加密的 KF7/KF8、混合容器、PalmDOC 和 HUFF/CDIC 压缩；读取书名、作者和封面 |

普通图书上限 256 MB，Kindle 解析上限 64 MB。密码保护的 Word、DRM 加密的 Kindle 文件和 KFX/Topaz 等其他容器不在此范围内。Word 和 Kindle 内容会转换为可调字号的正文；复杂页面布局、嵌入对象、批注和文档图片不作原版页面还原。

本地图书支持目录、书签、离线阅读、阅读位置恢复，以及已有的本地听书生成链路。阅读器提供原生卷页、横向滑动、滚动和无动画四种方式，并遵从系统的“减弱动态效果”设置。移除本地图书会清理其正文、位置和书签，保留原始导入文件。

## 当前能力

- iOS 17+，SwiftUI + SwiftData。
- 从 JSON 文本、文件或远程 URL 导入书源。
- 随 App 内置 25,968 条去重书源，支持按名称、分组、域名和兼容性筛选后导入。
- 从单个书源的排行榜与分类入口直接浏览书籍，支持常见文本和 JSON 榜单配置。
- 一键清理未启用且未被书架使用的冗余源，并用同一按钮快速跳到源列表顶部或底部。
- 导入前预览新增、更新和已有状态。
- 常用 Legado CSS 链式规则、CSS Selector、基础 JSONPath 与正则替换。
- 相对书源地址、当前节点属性、多页目录和单章多页正文连续读取；重复目录项按正文中的最终位置去重并重新编号。
- 搜索历史、详情、持久化目录、正文、后续两章自动预取和批量章节缓存。
- 书架列表/网格布局切换，书源按名称、分组或域名筛选并批量启停。
- 正文请求遇到超时或连接中断时自动重试，并用中文说明最终失败原因。
- 正文自动还原常见拼音敏感词混写，并清除汉字间的星号、全角遮挡符和零宽字符；普通英文保持原文。
- 搜索结果按书名或作者相关性排序、按作品聚合并可在详情页换源，同时过滤书源返回的推广伪结果。
- 章节内字符锚点、章节进度、全书进度和书架点击直接续读。
- 垂直滚动、水平滑动分页和无动画分页。
- 左右点击翻页、中央菜单、章节跳转和进度拖动。
- 最近阅读、今日/本周/本月/累计时长和阅读明细。
- 位置书签、书签摘要、书签列表和精确跳转。
- 阅读页内置听书入口，可通过二维码连接同一局域网的 Windows 生成器。
- 听书采用电脑整本预生成模式，手机只负责提交正文、同步伴读包和离线连续播放。
- GPT-SoVITS v2 ProPlus 声库提供 1 个旁白、5 个男声和 5 个女声，听书面板可以选择多角色自动分配或任一单人音色。
- 多角色模式根据引号、说话提示词、姓名及“他/她”线索稳定分配人物声线；同一人物跨章节保持相同音色。
- 生成器记录逐段角色时间轴；播放时滚动正文自动跟随并高亮当前段，分页正文自动翻到对应页。
- 已缓存章节可以一次快速提交给电脑，提交完成后电脑在手机离开听书页面的情况下继续生成。
- 电脑将已完成章节导出为 `.qraudio` 逐句伴读包，包内保存音频、多角色标识、UTF-16 时间轴以及正文和音频哈希。
- iPhone 可以通过局域网一键同步伴读包，也可以使用 Windows Apple Devices 数据线文件共享导入，导入后逐句高亮和离线播放保持一致。
- 章节正文由电脑本地转换为 M4A，下载后支持离线连续播放、后台播放、锁屏控制、15 秒快进后退和多档倍速。
- 听书任务按正文、音色和语速生成稳定标识，重复提交直接复用已经完成的音频。
- 听书音频按书籍管理占用空间，并支持一键删除整本音频。
- Windows 伴读台支持删除单章或整本电脑生成记录，状态变化时低频更新，并在网络切换后动态更新配对地址和二维码。
- 中文阅读界面、宋体正文、两字段首缩进、三档对称页面留白、字号、行距和四种纸张主题。
- 滚动与分页模式共享正文排版；分页首屏独立展示章节标题，并保留轻量页眉、页码和全书进度。分页计算与页面绘制共享 TextKit 排版参数并保留安全空间，页尾文字完整显示且下一页连续衔接。
- 无广告、无分析 SDK、无强制账号；需要认证的第三方书源可使用独立网页登录。

## 生成 Xcode 工程

项目使用 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 描述工程：

```bash
brew install xcodegen
xcodegen generate
open QuietReader.xcodeproj
```

Windows 环境不能运行 Xcode。项目按 [ios-ci-workflows Skill](https://github.com/wenjinliuu/ios-ci-workflows/blob/df71d6096d6d39ea799179cb2635703548b07ae0/skills/ios-ci-workflows/SKILL.md) 接入 **Build & Test**，CI 是编译和测试入口。

- 配置在 `.ios-ci.yml`，入口在 `.github/workflows/build-test.yml`；中央工作流固定为 [v1.1.0](https://github.com/wenjinliuu/ios-ci-workflows/releases/tag/v1.1.0) 的提交 `df71d6096d6d39ea799179cb2635703548b07ae0`。
- 分支推送、PR 和手动运行都会执行 `QuietReader` scheme 的全部单元测试；仅修改 Markdown 或 `docs/` 时跳过。当前不拆快线和慢线，也没有快照测试；手动输入的 `fast / ui / full` 在未配置分层计划时均运行主 scheme 的全部测试。
- 在运行页面的 job summary 查看“测试报告”，或下载 `build-test-<run>` 里的 `report/report.md`、`report/report.json`、`Test.xcresult` 和编译日志。
- iOS 测试通过后继续运行 Windows 听书协议回归并生成 `iBooks-ipa`，产物保留 14 天。下载后可使用 AltStore 或 Sideloadly 以自己的 Apple ID 签名安装。
- Xcode 固定为 `26.6`，模拟器为 `iPhone 17 Pro / iOS 26.4`。runner 不提供指定版本时，按 CI 报错中的可用列表更新 `.ios-ci.yml`；IPA job 中的 Xcode 版本也要同步更新。
- 当前接入等级 1（Build & Test），无需 Secrets。后续按需接入 TestFlight、Live Preview 和 App Icon。

`在线书源冒烟测试` 继续作为单独的手动工作流，使用 `QuietReaderLiveSources` scheme，避免第三方网站故障阻断固定回归。

## Windows 本地听书

Windows 生成器位于 [`Companion/AudiobookServer`](Companion/AudiobookServer)。已安装本项目的 GPT-SoVITS 环境后，双击 `打开墨阅听书.vbs` 即可使用 11 音色多角色声库；也可以使用系统自带的微软慧慧语音验证基础链路：

```powershell
cd Companion\AudiobookServer
python -m pip install -r requirements.txt
.\start.ps1 -Engine sapi
```

启动后，用电脑浏览器打开终端显示的配对地址。在 iPhone 阅读页点击耳机按钮，选择“连接电脑”并扫描二维码。手机与电脑可以连接同一个 Wi-Fi，也可以使用 iPhone 热点或数据线网络；伴读台会显示当前活动网络对应的地址。Windows 防火墙首次询问时允许网络访问。

需要预生成未读内容时，在阅读页打开听书面板，点击“缓存未读章节并提交电脑”。App 会从当前阅读章节开始补齐正文，最多并行读取 4 章，然后通过一个批量请求提交全部未读章节；已读章节不会再次提交。已有正文缓存时，局域网上传阶段通常只需数秒；首次缓存时间取决于书源网站响应速度。提交结束后，电脑会持久化队列并独立继续生成。之后重新连接，点击“同步电脑已完成伴读包”即可一次导入当前已完成章节。

生成器重启后会自动恢复已提交但尚未完成的任务。连接测试固定访问二维码地址的主端口健康接口，例如 `http://电脑地址:8765/v1/health`，只检查地址、配对码和协议版本，不会创建新的生成任务。App 会显示电脑当前恢复的运行与排队数量。

相同正文、音色和语速使用稳定任务 ID，重复提交会复用任务。再次提交同一章节的新正文或新音色时，生成器会移除该章节旧的排队与失败任务；已完成音频继续保留，正在合成的单章完成后停止旧配置的后续队列。

数据线传输时，在电脑生成器的 `data\packages` 中找到对应 `.qraudio` 文件。用 Windows Apple Devices 连接 iPhone，在“文件”中把该文件添加到墨阅，再在听书面板点击“导入 .qraudio 伴读包”。

CosyVoice 3 继续作为可选引擎，使用独立环境安装：

```powershell
cd Companion\AudiobookServer
.\install-cosyvoice.ps1
.\start.ps1 -Engine cosyvoice `
  -PromptAudio 'D:\voices\reader.wav' `
  -PromptText '这里填写参考音频中准确说出的文字。'
```

参考音频需要具有合法使用权。电脑只参与生成和传输，已下载章节保存在 App 沙盒中，离开局域网后仍可播放。百万字小说按 48 kbps 单声道 AAC 估算占用约 1 至 1.5 GB。

第三方书源的实时链路可在 Actions 中手动运行 `在线书源冒烟测试`。该测试会在 iPhone 模拟器中使用 App 自身的书源引擎读取所有启用精选源，并单独核验饿狼小说和森林文学的《异悚》目录数量、前三章顺序、连续索引、“第一章 第一个人”合并后正文长度及章末标记；不纳入每次提交的固定测试，以免第三方服务临时故障阻断正常构建。

## 书源边界

当前书源格式兼容 Legado 的常用顶层字段，以及搜索、发现、详情、目录和正文规则结构。引擎覆盖常用声明式规则，支持普通网页登录 Cookie 同步；暂不支持 Legado JavaScript 桥接、脚本登录界面、验证码自动处理、复杂 POST、XPath 和付费操作。

“书源”页的“内置源库”来自用户提供的全网合集：102,300 条原始记录经格式修复和“地址 + 名称”去重后形成 25,968 条目录，其中 6,103 条标记为当前兼容、15,186 条部分兼容、4,679 条暂不支持。完整规则按 64 个压缩分片随 App 分发，默认不批量启用，避免一次搜索向数千站点同时发起请求。

当前阅读器暂未实现手工文本高亮与笔记、跨设备同步、本地 EPUB/PDF。

导入页的“载入精选源”保留从用户合集筛选并转换的 5 条无需登录规则。饿狼小说、森林文学和快眼看书默认启用；B5200 因连接不稳定且《异悚》目录缺章，五二书库因把全书网页分页误作章节目录，均已移入备用组并默认停用。完整性检查会核验指定目录数量、正文长度、章末内容及目录结构。

正文解析会保留 `<p>`、块级元素和 `<br>` 表达的自然段，清除脚本、站点提示、分页标题与“本章未完”提示。阅读器以宋体、两字首行缩进、舒适行距和段落间距显示正文；升级后会自动刷新三个默认精选源留下的旧单行缓存。

分页正文使用同一组页眉、页脚、对称留白和章节标题高度常量计算可用区域，并额外预留两行重排安全空间。分页器与正文画布共享 TextKit 1 布局器，采用中文 Unicode 换行和标点挤压策略；回归测试会把所有页面文字重新拼接后与排版原文逐字比较，同时以小、中、大字号测量 SwiftUI 页面中正文画布的实际高度。

饿狼小说和森林文学的目录规则只读取“正文”区域，跳过页面顶部倒序展示的“最新章节”。引擎对分页目录中的重复 URL 保留最终位置，续读进度和书签优先按章节 URL 恢复，目录纠正后仍能回到原章节。

Legado 源码结构、界面能力和后续实现顺序见 [`notes/legado-gap-audit.md`](notes/legado-gap-audit.md)。

重新编译用户提供的源库：

```powershell
$env:PYTHONIOENCODING='utf-8'
python scripts\compile-source-catalog.py 'D:\开源阅读书源全网合集(2)' 'App\Resources\SourceCatalog'
python scripts\verify-source-catalog.py 'App\Resources\SourceCatalog'
```

仅应连接用户有权访问的内容服务。

### iBooks 本地导入与 EPUB 精排

应用显示名为 `iBooks`，设备产物名为 `iBooks.ipa`。橙色书本图标由 `scripts/generate-icon.ps1` 的矢量几何生成。

在“书库 → 右上角更多 → 导入图书”选取 EPUB、TXT、DOCX、DOC、MOBI、AZW、AZW3，也可从“文件”通过分享/打开送入应用。系统选择器先取得本机副本；关闭后显示逐文件结果，失败会说明原因。书源 JSON 应在“搜索 → 书源管理 → 导入书源”导入，JSON 打开链接会直接进入书源预览。

EPUB 使用 Readium 3.11.1，默认“原书精排”，完整保留原始归档中的 CSS、插图、字体、目录、锚点与固定版式，续读使用原生 Locator；底部显示全书百分比，避免把 EPUB 逻辑位置误称为真实页码。可在阅读菜单切换纸张、滚动、排版和书签。Word/Kindle 仍以正文提取方式阅读；不支持密码或 DRM 加密文件。普通文件上限 256 MB，Kindle 解析上限 64 MB，压缩包另有展开大小限制。

本次回归新增真实系统文件选择器选中 TXT / EPUB、导入结果、精排渲染和跨章节续读；原有取消导入、文本续读、书签及无障碍审计继续执行。UI 发生有意变化：主页阅读目标、书库列表/网格、阅读页悬浮控件和 EPUB 菜单；截图由 CI 导出。本地 Windows 未运行 Xcode 或真机验证。
